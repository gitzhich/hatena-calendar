# ADR-0002: X からの取得は公式 API のみとする

- status: 承認済み
- 日付: 2026-08-28

## 背景

出演情報を公式 X から取得する必要がある。
X API は 2026 年に月額プラン制から**従量課金**へ移行しており、
読み取りに費用が発生する。無料で済ませる手段としてスクレイピングもありうる。

## 決定

**公式 API（`GET /2/users/{id}/tweets`）のみを使う。スクレイピングしない。**

## 理由

- スクレイピングは X の利用規約違反であり、**アカウント停止のリスク**がある。
  情報源アカウントを失えばアプリそのものが成立しない
- 従量課金でも、`since_id` による差分取得なら**月 $1.5 程度**に収まる。
  1 アカウント・1 日 10 投稿の想定で月 300 リソース

## 検討した代替案

| 案 | 却下理由 |
| --- | --- |
| スクレイピング | 規約違反。BAN リスク |
| 手動入力のみ | 運用負荷が高く継続しない |
| 第三者の収集サービス | 信頼性と継続性が不明。規約上の問題も残る |

## 結果

- **`since_id` による差分取得が必須**になった。全件取り直しは再課金に直結するため、
  そのような実装経路を作らない
- 取得済み最大 tweet_id の永続化と単調増加の保証が必要になった
- テストから実 API を叩けない（課金されるため）。抽出ロジックを純粋関数に切り出し、
  記録済みレスポンスとサンプル本文でテストする
