# ADR（Architecture Decision Record）

設計上の決定と、その理由・検討した代替案を記録する。
**「なぜこうなっているか」を後から辿るための場所**であり、
仕様そのものは各設計文書（`docs/*.md`）を正とする。

## 運用

- ファイル名は `NNNN-短い説明.md`（連番は再利用しない）
- 一度承認した ADR の**決定内容は書き換えない**。方針が変わったら新しい ADR を起こし、
  古いものの status を `置き換え済み` にして新しい ADR へのリンクを追記する
- **決定が変わらない範囲の補足**（理由の追記、リンクの修正、誤字）は追記してよい。
  その場合は末尾の「更新履歴」に何を足したかを残す
- 記録するのは**後から覆すコストが高い決定**に限る。
  実装の細部は設計文書のコメントで足りる
